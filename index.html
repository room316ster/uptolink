🛡️ ตั้งค่า Admin Login ครั้งแรก
ยังไม่ได้ตั้งค่า Vault

ตั้ง Username และ Password สำหรับผู้ดูแล แล้วระบบจะเข้ารหัส GitHub Token ด้วย AES-256-GCM เพื่อไม่ให้ Token ถูกเปิดเผยในซอร์สโค้ด

1. บัญชีผู้ดูแลระบบ
2. ข้อมูล GitHub Repository
🔒 ต้องเปิดสิทธิ์ Contents: Read and write · Token จะถูกเข้ารหัสก่อนบันทึกทุกครั้ง
3. นำ Vault ที่เข้ารหัสแล้วไปใช้งานข้ามเครื่อง

บันทึก Vault ลงเบราว์เซอร์เครื่องนี้แล้ว! หากต้องการล็อกอินด้วย Username + Password จากเครื่องอื่นหรือมือถือ ให้กด อัปเดตขึ้น index.html บน GitHub หรือคัดลอกโค้ดด้านล่างไปแทนที่บล็อก ADMIN_VAULT ในไฟล์ index.html
